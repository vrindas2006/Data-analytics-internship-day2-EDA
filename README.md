# Exploratory Data Analysis – Sample Superstore

## Internship
Veda Technologies – Data Analytics Internship

## Task
Day 2 – Task 2: Exploratory Data Analysis (EDA)

## Objective
The objective of this project is to perform Exploratory Data Analysis (EDA) on the Sample Superstore dataset and identify important patterns, relationships, trends, and outliers.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Summary statistics
- Data quality check
- Correlation heatmap
- Sales distribution
- Profit outlier analysis
- Sales vs Profit relationship
- Sales by category
- Profit by category
- Monthly sales trend

## Key Insights
1. Sales and Profit show a generally positive relationship.
2. Technology is one of the strongest-performing categories.
3. Higher discounts can be associated with lower profitability.

## Files
- `Task_2_Exploratory_Data_Analysis.ipynb` – Jupyter Notebook containing the complete EDA.
- `SampleSuperstore.csv` – Dataset used for the analysis.
